# 🌌 Projeto Borrow Books — Simulador de Biblioteca Pública

## Propósito

Construir um sistema web que represente as operações essenciais de uma biblioteca pública: acervo, cópias, empréstimos, devoluções, papéis (ADMIN, BIBLIOTECARIO, USER) e histórico.  
Objetivo pedagógico: consolidar fundamentos de engenharia web com rigor profissional.

## Escopo do MVP

- CRUD de Usuários, Livros e Empréstimos.
- Regras: controle de cópias, limite por usuário e bloqueio quando indisponível.
- Autenticação e autorização (RBAC).
- Interface web funcional e clara.

## Critérios de Sucesso

- Fluxo ponta a ponta (login → empréstimo → devolução).
- Controle de cópias respeitado.
- Histórico verificável por usuário e livro.
- Projeto legível e auditável.

## Tom e Valores

Clareza, previsibilidade, originalidade disciplinada.  
Decisões explícitas e documentadas.

## Público-Alvo

Recrutadores e engenheiros; Bruno como aprendiz em transição para pleno.
