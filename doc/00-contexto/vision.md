# Projeto: Simulador de Biblioteca Pública

## Propósito

Construir um sistema web que represente as operações essenciais de uma biblioteca pública: acervo, cópias, empréstimos, devoluções, papéis (admin, bibliotecário, usuário) e histórico. O objetivo pedagógico é consolidar fundamentos de engenharia web com rigor profissional.

## Escopo do MVP

- CRUD de Usuários (com roles), Livros e Empréstimos.
- Regras: controle de cópias, limite por usuário, bloqueio quando indisponível.
- Autenticação e autorização (RBAC).
- Interface web funcional (mínima, clara).

## Critérios de Sucesso (MVP)

- Operações básicas funcionando ponta a ponta (login → empréstimo → devolução).
- Regras de cópias respeitadas e verificáveis.
- Histórico acessível por usuário e por livro.
- Projeto legível para recrutadores (estrutura, commits, docs).

## Tom e Valores

Clareza, previsibilidade, originalidade disciplinada. Sem floreio: código e decisões com propósito explícito.

## Público-Alvo

Recrutadores e engenheiros que avaliam portfólios; você (Bruno) como aprendiz em evolução para pleno.
